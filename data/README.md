# Data

Patient-level, pseudonymised clinical data collected under the General Data Protection Regulation. For the authors' own replication only; do not distribute. The public repository omits this folder's data files and three per-patient result files (`outputs/results/rehab_linked_cohort.csv`, `outputs/results/contribution_*.csv`).

- `source_registry.ods`: thrombectomy registry, sheet `Data`
- `rehabilitation_outcomes.ods`: neurorehabilitation unit register

SHA-256 of both files is recorded in `outputs/results/results_manifest.json` under `_provenance`.
